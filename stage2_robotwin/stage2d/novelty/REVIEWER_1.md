# Independent reviewer 1

## Verdict

`BLOCK_FULL_V2_NOVELTY_INTERPRETATION / PARTIAL_MECHANISM_DISTINCT`

The current analytic code isolates one narrow executable distinction: an externally
specified desired contribution target differs from self-targeting current
contribution.  It does not yet execute the complete frozen V2 chain
`donor-fade capacity -> phase/safety state -> desired responsibility -> 4D allocator`.

## Evidence and blockers

- A3 self-targeting has mean absolute share movement 0.000791; A4 external target
  reaches MAE 0.013723; A5 reverses movement in the constructed testbed.
- Stage 2C already contained a 4D target-driven nullspace allocator.  The distinct
  part under test is target provenance, not merely dimensionality.
- The initial analytic case had no donor-fade capacity or state machine; `delay` and
  partial failure did not drive the target.
- A4's optimization loss and evaluation share are structurally aligned, so its win
  proves target following, not that the target is causally correct.
- A3 is an algebraic self-target control, not a replay of Stage 2C's unstable Shapley
  estimator.
- A1 was a no-op because the base exactly preserved net effect.  A7's internal-force
  comparison is therefore descriptive; the direct A4/A7 trade-off is more relevant.
- The analytic operator has no contact or collision constraints and A4 modifies the
  action by 58.8% on average.

Maximum supported claim before RoboTwin evidence: a perfect-model synthetic allocator
can track an external target while approximately preserving net effect; self-targeting
does not initiate a transfer.  No takeover-capacity, contact-safety, closed-loop,
deployability, policy, or N3 novelty claim is supported.
