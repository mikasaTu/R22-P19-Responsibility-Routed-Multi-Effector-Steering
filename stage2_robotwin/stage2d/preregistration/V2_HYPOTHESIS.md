# Stage 2D / V2 frozen hypothesis

Stage 2C falsified routing toward *currently measured* responsibility.  V2 therefore
separates three quantities that must not be conflated:

1. **Actual contribution**: the effect currently produced by an effector.
2. **Counterfactual takeover capacity**: whether an effector can preserve future task
   progress after the other effector is faded out from the same state.
3. **Desired responsibility**: a task-state target for the next phase, produced from
   takeover capacity plus phase and safety constraints.

The frozen causal claim is narrow: when the receiver has counterfactual takeover
capacity, a constrained four-dimensional effect allocator can move its actual
contribution toward an independently specified desired target while preserving net
object effect, support, and contact safety.  Desired responsibility is never set to
current measured responsibility.

## Falsifiers

The claim is falsified at analytic level if the correct target does not beat swapped
and random targets, swapped targets do not reverse contribution movement, mean
tracking MAE exceeds 0.15, net-effect relative error exceeds 0.05, feasibility is
below 90%, or internal force exceeds conservation-only.  Downstream experiments are
still executed when requested, but are labeled `INELIGIBLE_UPSTREAM_GATE` and cannot
rescue an analytic failure.

No learned policy or learned capacity estimator is in scope unless the complete
oracle V2 gate passes.  Stage 2D does not inherit a novelty grade from Stage 2C.
