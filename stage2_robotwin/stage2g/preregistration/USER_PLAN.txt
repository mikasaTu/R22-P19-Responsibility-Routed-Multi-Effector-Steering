# 已确定的前提（审计结论，不需重新论证，也不许推翻）
1. Stage 2F 矩阵作废，四个独立原因：
   (a) K2 是死钩子——真实关节 force_limit = 3.4028e38 (FLT_MAX)，乘任何 gamma 仍远高于实际力矩，
       永不 binding；单测里 FakeJoint 用 force_limit=50 掩盖了它。
   (b) G4 的 donor 判据与事件定义矛盾——配置里 E5 = donor_contact_lost_after_E4，
       而 G4 要求 donor 在 E5 仍有接触；smoke 里名义 gamma=1.0 就是 false。
   (c) G1 量的是 soft 臂平行冲量绝对积分；smoke 里它涨 73% 而 soft/receiver 份额 0.4554→0.4505
       几乎不动，说明涨的是内力不是权威。
   (d) G5 对 K1/K2 测的是跟踪误差：命令 target 跨 gamma 逐字节相同，
       但 parallel_action_abs 在 17/17 个状态于 gamma=0.2 更大，方向与门相反。
2. K1 的反向有确定机制：authority_override 把刚度与阻尼同乘 gamma，
   阻尼比 zeta = D/(2*sqrt(I*K)) 变为 sqrt(gamma)*zeta，gamma=0.2 时只剩 0.447 倍，
   欠阻尼导致峰值速度 +83%、冲量 x1.73。任何复用 K1 的地方必须改成刚度乘 gamma、阻尼乘 sqrt(gamma)。
3. Stage 2E 已证明：闭链下改 target 不改物理效应；唯一改变物理效应的通道是 retention（夹爪）。
   本步据此把夹持力作为权威旋钮，这不受 2E "会移除所有 channel" 那条反对意见约束，
   因为本步要的正是整臂权威而非 channel-selective withdrawal。
4. 不换 substrate：RoboTwin handover_block，planner mplib_screw，physics 250 Hz，
   沿用 Stage 2D 的 active handover 版本。

# 要实现的东西
新建 stage2_robotwin/stage2g/{preregistration,probe,intervention,analysis,scripts,tests,reports,results}/

1. probe/dual_frequency.py —— 双频差分探针
   - 沿 e_perp 给左右臂注入 offset_side(t) = A * sin(2*pi*f_side*(t-E3)/250)，区间 E3..E5
   - 与 Stage2F 同样的纪律：先做一次名义重放把整条命令 tape 冻成 npz + sidecar，
     之后所有条件只读同一份字节；禁止 live Jacobian 生成（Stage2F v1 的教训）
   - 频率对 (f_L,f_R) 取 (1.0,2.5) 与对调的 (2.5,1.0) 两套，各自单独冻结一条 tape
   - 幅度 A 在 smoke 里试 0.003 / 0.005 / 0.008 m，按 gate 冻结一个值

2. intervention/grip_force.py —— K4 夹持力权威旋钮，接口 apply(task, soft_arm, gamma)
   - gamma=1 名义夹持力（必须逐字节 no-op），gamma→0 夹持力趋近松开阈值
   - 只改 soft 臂夹爪，手臂关节的 stiffness/damping/force_limit/drive_mode 一律不动
   - 在 finally 里精确复原并出 receipt；SapienSnapshot 不含这些属性，不要指望它还原
   - 如果 RoboTwin 的夹爪接口只暴露开合位置而非力，就用夹爪目标开度做等价旋钮，
     并在报告里写清楚实际改的是什么物理量，不要假装是力

3. analysis/wrench_decomposition.py —— 净力/内力诊断
   - 每步对每只手求它作用在物体上的 6D wrench：w_i = sum over contacts [f_c ; (p_c - c_obj) x f_c]
   - w_ext = w_L + w_R（推动物体的那部分）；w_int = (w_L - w_R)/2（互相挤的那部分）
   - 输出每步的 |w_int| / (|w_ext| + |w_int|)
   - 对 Stage2F 的两个 smoke cell 追溯计算：柔顺化引起的 delta_w 有多大比例落在内力上
   - 这一项只报告不设门，是机制解释用的

4. analysis/authority_ratio.py —— 权威占比
   - 取物体在 e_perp 上的位移序列，限定 E3..E5 窗口，去趋势 + Hann 窗 + FFT
   - a_soft = A(f_soft) / (A(f_soft) + A(f_receiver))
   - 同时输出各频点的相干性与整段 0.3-5 Hz 的噪声底

# 冻结 gate（跑之前写进 preregistration，跑完不许改）
仪器（全部必须过，否则直接停）：
- I1 分离度：f_L 与 f_R 处的位移谱峰均 >= 该频带噪声底中位数的 10 倍
- I2 泄漏：单臂探针条件下，未注入频率处的幅值 <= 注入频率幅值的 0.10 倍
- I3 对调一致：同一 (seed, soft_arm) 下，两套频率对给出的 a_soft 绝对差 <= 0.10
- I4 地面真值：锁死一侧时，另一侧的 a >= 0.85
- I5 非侵入：探针条件下 dual-contact fraction >= 0.95 且 task success >= 0.9

旋钮（阶段 I 全过后才评估）：
- A1 单调：Spearman(grip_gamma, a_soft) >= 0.9，每个 seed x soft_arm 组都要满足
- A2 幅度：最低非退化 gamma 处的 a_soft <= 名义值的 0.6 倍，
          且该差值 > 3 x (同条件两次 repeat 的 a_soft 绝对差的 P95)
- A3 非退化：所有 gamma >= 0.15 时 dual-contact >= 0.95、物体未掉落、
          物体相对夹爪滑移 < 5 mm、task success >= 0.8
- A4 隔离：receiver 臂命令逐字节不变；探针 tape SHA 在同一 seed 内跨所有条件相同
- A5 对照（只报告不设门）：同条件下用旧的 NaturalResponsibilityEstimator 算 rho_soft，
          与 a_soft 并列，展示两者是否一致

决策，写入 results/AUTHORITY_PROBE_DECISION.json：
- 仪器门任一失败 → AUTHORITY_PROBE_INVALID，停线，不要提改任务或改 substrate
- 仪器过、A1-A4 全过 → AUTHORITY_TRANSFER_SUPPORTED，冻结最大非极端 gamma 供 Step10
- 仪器过、A1 或 A2 失败 → AUTHORITY_TRANSFER_NOT_SUPPORTED
- 仪器过、A1/A2 过但 A3 失败 → AUTHORITY_TRANSFER_DEGENERATE
